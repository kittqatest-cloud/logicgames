# Hoot Quest

Пятнадцать обучающих игр для детей 4–8 лет. Сова-учительница читает задания вслух, играет тихая музыка, за звёздочки открываются наклейки.

**Играть:** https://kittqatest-cloud.github.io/logicgames/

| Игра | Что тренирует |
|---|---|
| Лабиринт | планирование, ориентация |
| Найди отличия | внимание |
| Запомни картинки | зрительная память |
| Найди пару | память |
| Рисуем по точкам | моторика, ориентация на листе |
| Графический диктант | слуховое внимание, ориентация в клетках |
| Чья тень? | восприятие формы |
| Что лишнее? | классификация, логика |
| Разложи по корзинкам | обобщение, группировка |
| Загадки | речь, образное мышление |
| Продолжи ряд | закономерности |
| Сосчитай | счёт до 15 |
| Космический счёт | сложение и вычитание до 20: ракета летит к Луне сквозь астероиды с ответами |
| Выведи машинку | планирование на ходы вперёд: пять парковок (двор, город, стройка, порт, каток), каждый уровень проверен на минимум ходов |
| Крестики-нолики | стратегия, предвидение ходов: шесть миров с друзьями совы, от совёнка до мудрой совы, большое поле 5×5 и исчезающие фишки |

При первом входе сова знакомится: спрашивает имя и возраст, и по возрасту выбирает сложность. В каждой игре три уровня: «Легко», «Средне», «Сложно»; в крестиках-ноликах и «Выведи машинку» вместо них карта — дорожка из шести уровней в каждом мире, последний из них испытание, а за пройденный мир открывается сундук с подарком. За задание до 3 звёздочек, ошибки не наказываются — сова подсказывает. Три игры в день приносят подарок от совы. Прогресс хранится в браузере устройства.

Сова говорит на трёх языках: русском, украинском и английском. Язык выбирается кнопкой RUS / UKR / ENG на главном экране, при первом знакомстве и в разделе «Для родителей», и вместе с ним меняются голос, названия игр, подсказки и загадки. Новый гость сразу получает язык своего браузера.

Кнопкой 🌙/☀️ переключается тема: днём светлый луг с солнцем, вечером тёмное небо с луной и звёздами. Пока ребёнок сам не выбрал, тема идёт по часам: с 19:00 до 7:00 ночная.

На iPad и iPhone лучше открыть сайт в Safari и нажать «Поделиться» → «На экран Домой»: игра откроется на весь экран, как приложение, и Safari не сотрёт прогресс, даже если долго не играть.

Все картинки, фоны, сова и элементы интерфейса нарисованы с помощью Gemini в одном мягком объёмном стиле; днём луг с солнцем и бабочками, вечером луна, звёзды и светлячки.

Озвучка записана заранее нейроголосами Microsoft: Светлана (русский), Поліна (украинский) и Ana (английский); музыка генерируется в браузере.
