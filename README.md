# Hoot Quest

Двенадцать обучающих игр для детей 4–8 лет. Сова-учительница читает задания вслух, играет тихая музыка, за звёздочки открываются наклейки.

**Играть:** https://kittqatest-cloud.github.io/logicgames/

| Игра | Что тренирует |
|---|---|
| Лабиринт | планирование, ориентация |
| Найди отличия | внимание |
| Запомни картинки | зрительная память |
| Найди пару | память |
| Рисуем по точкам | моторика, ориентация на листе |
| Графический диктант | слуховое внимание, ориентация в клетках |
| Чья тень? | восприятие формы |
| Что лишнее? | классификация, логика |
| Разложи по корзинкам | обобщение, группировка |
| Загадки | речь, образное мышление |
| Продолжи ряд | закономерности |
| Сосчитай | счёт до 15 |

При первом входе сова знакомится: спрашивает имя и возраст, и по возрасту выбирает сложность. В каждой игре три уровня: «Легко», «Средне», «Сложно». За задание всегда 3 звёздочки, ошибки не наказываются — сова подсказывает. Три игры в день приносят подарок от совы. Прогресс хранится в браузере устройства.

Кнопкой 🌙/☀️ переключается тема: днём светлый луг с солнцем, вечером тёмное небо с луной и звёздами. Пока ребёнок сам не выбрал, тема идёт по часам: с 19:00 до 7:00 ночная.

На iPad и iPhone лучше открыть сайт в Safari и нажать «Поделиться» → «На экран Домой»: игра откроется на весь экран, как приложение, и Safari не сотрёт прогресс, даже если долго не играть.

Все картинки, фоны, сова и элементы интерфейса нарисованы с помощью Gemini в одном мягком объёмном стиле; днём луг с солнцем и бабочками, вечером луна, звёзды и светлячки.

Озвучка сделана заранее синтезатором [Piper](https://github.com/rhasspy/piper) (голос ru_RU «Ирина»), музыка генерируется в браузере.
